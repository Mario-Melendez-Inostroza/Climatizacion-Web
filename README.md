# Soluciones Integrales M&N — Gasfitería, Climatización y Electricidad

Sitio web (landing page) de **Soluciones Integrales M&N**, empresa de servicios técnicos de gasfitería, climatización y electricidad en Santiago, con técnicos certificados SEC.

**Sitio en vivo:** https://climatizacion-web.vercel.app/

## Secciones

- Inicio, Servicios, Nosotros y Contacto
- Botón de contacto directo por WhatsApp

## Stack

- React + TypeScript
- React Router
- Vite
- Tailwind CSS
- Despliegue en Vercel

## Cómo ejecutarlo

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción
```
